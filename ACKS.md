# Implementer acknowledgements

When a version is frozen, each implementer signs its **freeze hash** (the SHA-256 of the git tree at the freeze tag, plus the `vectors/` directory digest) with its AMP root key, and records it here. An X post saying "we're in" is not an acknowledgement.
